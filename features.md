# Application Features

## Purpose
Squad Production Platform is a minimal web application built by a student
team to practice professional Agile and Git workflows. It will eventually
be deployed to a public URL via a CI/CD pipeline.

## Planned Features
- **User authentication** — users can register and log in with email/password.
- **Task creation** — authenticated users can create personal tasks.
- **Task listing** — users can view all their tasks in a single dashboard.
- **Task completion** — users can mark tasks as done.
- **Task deletion** — users can delete tasks they no longer need.

## Out of Scope (for this course)
- Team/shared task assignment.
- Notifications or email digests.
- Mobile clients.
